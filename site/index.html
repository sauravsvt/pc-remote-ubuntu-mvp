Public work · Linux and Windows

Your computer, from your phone.

PC Remote is a local page for one computer. It can lock the session, change the volume, and turn the screens off. The computer keeps running. Nothing is streamed.

install.sh 
curl -fsSL https://pcremote.voxonlabs.com/install.sh | bash

Lock and sound

Lock the session, mute, unmute, and set the volume. Leaving does those and turns the screens off in one tap.

Screens off

The displays go dark and the computer stays on. On Linux, individual monitor buttons appear when DDC/CI can see them.

Ubuntu is the system this has been used on. Windows uses the same buttons; try lock, volume, and screens once while you are at the desk. Review the installer before piping it to a shell.

Use it from your phone

  1. 1. Install it on the computer

    Run the command above while you are signed in to the desktop, then read the token.

    cat ~/.config/pc-remote/token

    Run the command above. The installer opens the controls on this PC, already signed in. Approve the Tailscale prompt if Windows asks.

    If the page does not appear, open http://127.0.0.1:8765 on that computer.

  2. 2. Install Tailscale on that computer

    Install Tailscale for Linux from tailscale.com/download/linux, then sign in:

    curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

    The Windows installer downloads Tailscale if it is missing and asks you to sign in. Approve the administrator prompt. Use the same account as your phone.

    Use the account you will also use on the phone. Review Tailscale’s installer before piping it, the same way you review this one.

  3. 3. Install Tailscale on the phone

    Install the Tailscale app from the App Store or Google Play and sign in to the same account. The phone and the computer should both show as connected in the Tailscale app.

  4. 4. Give the phone a private address

    On the computer, this publishes the page to your tailnet only. It does not put port 8765 on the public internet.

    tailscale serve --bg http://127.0.0.1:8765
tailscale serve status

    On Windows the installer publishes the page and prints an https address ending in ts.net. You do not type this command yourself.

    If the command says permission denied, run it with administrator rights. Do not run tailscale funnel, and do not forward port 8765 on your router.

  5. 5. Open it and keep the token

    tailscale serve status prints an HTTPS address ending in ts.net. Open that address in the phone’s browser, enter the token from step 1, and use the browser menu to add the page to the home screen.

    Install the Tailscale app on the phone, sign in with the same account, and open the link the installer printed. That link already contains the token. Add the page to the home screen. Do not send the link in a chat or a screenshot.

    The token stays on that phone until you press Forget token. If the computer rejects it, the page clears it and asks again. Do not send the token in a chat or a screenshot.
